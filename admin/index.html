The first time you use admin on a phone or computer, it needs a key from your GitHub account. That key is what lets this page save changes to the website. You only do this once on each device. La primera vez que usás el admin en un teléfono o computadora, necesita una clave de tu cuenta de GitHub. Esa clave es lo que permite guardar cambios en la página. Se hace una sola vez en cada dispositivo.

  1. Open GitHub (you need to be logged in):Abrí GitHub (tenés que estar logueado): Create the key on GitHubCrear la clave en GitHub
  2. In Expiration choose No expiration. Leave the rest as it is, scroll down and click Generate token. En Expiration elegí No expiration. Dejá el resto como está, bajá y hacé clic en Generate token.

      Visitor stats come from GoatCounter, a free, privacy-friendly counter (no cookies, so no cookie banner needed). It needs a free account, created once: Las estadísticas vienen de GoatCounter, un contador gratis y respetuoso de la privacidad (sin cookies, así que no hace falta aviso de cookies). Necesita una cuenta gratis, que se crea una sola vez:

      1. Open GoatCounter and sign up:Abrí GoatCounter y registrate: Sign up on GoatCounterRegistrarse en GoatCounter
